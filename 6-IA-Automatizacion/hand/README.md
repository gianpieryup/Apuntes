# Detección de Manos con MediaPipe

Sistema de detección de manos en tiempo real usando MediaPipe Tasks API (versión nueva).

## Instalación

```bash
pip install opencv-python mediapipe
```

## Uso

```bash
python h.py
```

## Requisitos

- Python 3.8+
- Cámara web
- Windows/Linux/Mac

## Características

- Detección de hasta 2 manos simultáneas
- 21 landmarks por mano (articulaciones)
- Conexiones visuales entre puntos
- Modo VIDEO para mejor rendimiento en tiempo real
- Descarga automática del modelo en primera ejecución

## Controles

- `q` - Cerrar programa
